# PacketPath — CCNA Study Site

A small, dependency-free study site for the Cisco CCNA 200-301: learning path, flashcards, practice questions, and progress saved in the browser.

## Run it

Open `index.html` in a browser. No build step.

## Edit it

- Study modules, flashcards, and quiz questions: top of `script.js`
- Look and feel: `styles.css`

## Where it's hosted

A copy lives in the portfolio repo at `public/apps/ccna/` and is served at <https://reid-json.net/apps/ccna/index.html>.
After changing files here, copy `index.html`, `styles.css`, and `script.js` into that folder in the [Portfolio](https://github.com/reid-json/Portfolio) repo and push.
